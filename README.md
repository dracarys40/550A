550A SERIES — App Guide
A simple guide to the apps in the 550A web desktop. Open any app by double-clicking its desktop icon or choosing it from the Start menu.

📁 Files
Open Files from the desktop or Start menu.

Use the sidebar to go to Home, Desktop, Documents, Downloads, Pictures, Music, This device, or Network.

Single-click a card to select it, double-click a folder to open it, or type a location in the address bar and press Go.

⚙️ Settings
Open Settings from the desktop or Start menu.

Pick a page from the left: System, Personalization, Networks, Accounts, Privacy, Updates, Apps, or Storage.

Change what you need, such as brightness, volume, theme, accent color, transparency, wallpaper, or power mode.

📝 Quick Notes
Open Quick Notes from the desktop or Start menu.

Click inside the note area and start typing.

Close the window when finished. Notes last only for the current session.

🔢 Calculator
Open Calculator from the desktop or Start menu.

Choose Basic or Scientific mode at the top.

Enter numbers and operators, then press equals. Click a history item to reuse a result.

📅 Calendar
Open Calendar from the desktop or Start menu.

Move through months with Today, the arrows, or the month and year menus.

Select a day, type an event title and optional time, then click Add event. Use the × to remove an event.

🎵 Music Player
Open Music Player from the desktop or Start menu.

Pick a song from the library or click + Add music to choose your own audio files.

Use play, pause, next, previous, shuffle, repeat, seek, and volume controls.

💻 Terminal
Open Terminal from the desktop or Start menu.

Type a command such as help, apps, open calculator, theme light, or volume 50.

Press Enter to run it. Use the Up and Down arrow keys to revisit previous commands.
